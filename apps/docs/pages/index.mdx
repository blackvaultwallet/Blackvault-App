# Welcome to BlackVault

**Private banking on Robinhood Chain.** Stealth transfers, pay-by-name, and a
Face ID vault — private by default, auditable by choice.

BlackVault is a self-custodial wallet where payments never link sender to
receiver on-chain. Sign in with Google, receive to
`you.blackvaultwallet.eth`, and keep every balance yours to reveal — while
your IP never appears next to your address on any third-party server.

## How it works

| Layer | Mechanism |
| --- | --- |
| Privacy | ERC-5564 stealth addresses + canonical ERC-6538 registry |
| Names | ENS subnames · CCIP-Read (ENSIP-10) signed gateway |
| Network | Robinhood Chain mainnet · chainId `4663` · sub-cent fees |
| Custody | Embedded wallets (Privy) · passkeys · exportable key |
| Metadata | Same-origin proxies for RPC, prices, news, images |
