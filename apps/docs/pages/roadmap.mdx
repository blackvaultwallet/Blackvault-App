# Roadmap

Where BlackVault is heading. Order reflects intent, not promises — shipping
safely beats shipping fast.

## Live today

- Stealth transfers (ERC-5564) on Robinhood Chain mainnet
- BlackVault Names with on-chain-verified paid claims
- Private payment requests (QR + link)
- Biometric vault lock, activity journal, news & markets hub

## Coming soon [#coming-soon]

Detailed docs for what's being built now:

| Milestone | What it unlocks |
| --- | --- |
| [**Private Balance**](/coming-soon/private-balance) | Amount-hiding shielded pool — your balance becomes fully invisible |
| [**Private Degen**](/coming-soon/private-degen) | Shielded trading for RH Chain tokens — positions never linked to your public wallet |
| [**BlackVault Card**](/coming-soon/card) | Spend your vault balance in the real world, privately |
| [**Multichain**](/coming-soon/multichain) | Ethereum, Arbitrum, Base, Optimism — the switcher is already in the UI |
| [**Names API & SDK**](/coming-soon/names-api) | Issue and resolve BlackVault Names from your own app |

## Also in flight

- **Names everywhere** — mainnet activation of the CCIP resolver so
  `you.blackvaultwallet.eth` resolves in every ENS-aware wallet.
- **Stealth indexer** — a server-side scanning pipeline for instant
  incoming-payment detection at scale.
- **NFC tap-to-pay** — pay between devices with a tap.

## Principles that won't move

Private by default. Auditable by choice. Self-custody always — every feature
ships with an exit door and your keys in your hands.
